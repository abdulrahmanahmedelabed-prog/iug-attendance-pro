# لماذا لم تنجح النسخة v41 في أن تكون مثل BioTime — وما الذي تغيّر في v42

راجعتُ ملف `ZK_Attendance_Pro_v41.1.0_BIOTIME_STYLE.zip` كاملاً (≈180 ملف بايثون، 40 ملف API، 48 ملف اختبار).
المشكلة لم تكن في تفصيلة واحدة، بل في الاتجاه:

## 1. القناة الخطأ

BioTime **لا يتصل بالجهاز عبر TCP 4370** إطلاقاً؛ الجهاز هو من يتصل بالخادم عبر **ADMS (HTTP Push)**.
أغلب جهد v11 → v41 ذهب إلى TCP 4370 (المصافحة، مفتاح الاتصال، `0x0075`, `CMD_AUTH`, قراءة الكتل الخام، COM SDK
للكف...) بينما خادم ADMS — وهو قلب BioTime — كان هذا فقط:

```python
@router.get('/iclock/getrequest')
async def getrequest(): return PlainTextResponse('OK')      # لا يرسل أي أمر للجهاز أبداً
@router.api_route('/iclock/devicecmd', ...)
async def devicecmd(): return PlainTextResponse('OK')       # يتجاهل نتائج الأوامر
# cdata: يرد OK على المصافحة بدل كتلة الإعدادات، ويتجاهل OPERLOG/BIODATA (المستخدمين والقوالب)
```

النتيجة: الجهاز يتصل، لكن الخادم لا يستطيع أن يرسل إليه موظفاً، ولا يستقبل منه وجهاً أو بصمة، ولا يزامن الوقت،
ولا يعرف قدراته. أي أنه لا يمكن أن يعمل «مثل BioTime» مهما أُضيف فوقه.

## 2. التراكم بدل التصميم

كل إصدار أضاف ملفاً جديداً (`api_v24.py` … `api_v41.py`, `fleet_v28`, `fleet_v39`, `palm_sdk_v40`, `palm_sdk_v40_1`…)
وصفحة جديدة (`/v24` … `/v41`) وجداول جديدة (`sync_jobs_v28`, `fleet_inventory_v39`, `palm_resolution_v401`…)
دون حذف القديم. فأصبح هناك عدة جداول للأجهزة وعدة جداول للموظفين وعدة محركات مزامنة، والبيانات لا تلتقي.

## 3. غياب محرك الحضور

جداول `timetables` و `schedules` كانت موجودة لكن فارغة وغير مستخدمة؛ لم يكن هناك احتساب للتأخير والغياب
والإضافي والورديات الدورية والدوام الليلي، وهو ما يجعل BioTime برنامج حضور وليس مجرد قارئ بصمات.

## ما الذي بُني في v42

| BioTime 9.5 | v41 | v42 |
|---|---|---|
| خادم ADMS كامل (مصافحة، رفع، أوامر، نتائج) | يرد OK فقط | ✓ كامل + `querydata` + `rtdata` + `registry` + `tabledata` |
| المناطق وتوزيع الموظفين على الأجهزة | ✗ | ✓ تلقائي عند كل تعديل |
| استقبال وتوزيع قوالب الوجه/البصمة/الكف | ✗ | ✓ مع فحص توافق الخوارزمية وإرسال صورة الوجه كبديل |
| أوامر الأجهزة (مزامنة، وقت، إعادة تشغيل، مسح، تسجيل عن بعد) | ✗ | ✓ مع طابور ونتائج وإعادة محاولة |
| أوقات الدوام، الورديات، الجداول، العطل، الإجازات، الإضافي، الاعتماد | جداول فارغة | ✓ محرك كامل + 13 تقريراً |
| واجهة موحدة | صفحة لكل إصدار | ✓ واجهة واحدة بأسلوب BioTime، عربية/إنجليزية |
| المستخدمون والصلاحيات والنسخ الاحتياطي | جزئي | ✓ |

ما احتُفظ به من الفكرة القديمة: سحب TCP 4370 أصبح **خياراً احتياطياً** فقط (زر واحد، عبر مكتبة pyzk) للأجهزة التي لا تدعم ADMS.
